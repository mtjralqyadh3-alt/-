# Apax Security

مشروع Android Native بلغة Kotlin يجمع بين فحص التطبيقات المثبتة وخزنة ملفات مشفرة وواجهة آلة حاسبة. التنفيذ يعتمد على APIs النظام الفعلية، ولا يعرض تقدماً أو نتائج أمنية غير محسوبة.

## ما الذي ينفذه المشروع؟

يقرأ `PackageManager` التطبيقات المرئية للتطبيق، ويستخرج الأذونات المطلوبة ثم يحدد الأذونات الحساسة التي تظهر كممنوحة فعلياً. درجة المخاطر المعروضة هي heuristic شفافة مبنية على عدد الأذونات الحساسة الممنوحة وليست حكماً مضاداً للفيروسات. كما يحتفظ مسار APK المصدر إن كان متاحاً.

يطلب التطبيق من المستخدم تفعيل `MANAGE_EXTERNAL_STORAGE` من صفحة إعدادات Android، ويطلب أذونات الوسائط runtime. لا يمكن للكود تفعيل هذه الصلاحيات بنفسه. يختار المستخدم الملفات عبر Storage Access Framework، ثم تُشفّر داخل `filesDir/vault` باستخدام مفتاح AES-256-GCM محفوظ في Android Keystore.

واجهة الآلة الحاسبة تنفذ العمليات الأساسية `+ - * /`. إدخال الرمز المحدد يمر عبر SHA-256 ويُفتح بعد تطابق التجزئة؛ لا يُحفظ الرمز الخام في تفضيلات أو ملف.

يحتوي التطبيق أيضاً على `Apax Home` كـ Launcher اختياري. بعد اختيار Apax Home كتطبيق الشاشة الرئيسية الافتراضي من إعدادات Android، تظهر التطبيقات القابلة للتشغيل في واجهته. الضغط المطول على أي تطبيق يخفيه من قائمة الظاهرة، ويظهر التطبيق في قسم **التطبيقات المخفية داخل Apax**؛ الضغط عليه يفتحه، والضغط المطول عليه يعيده إلى القائمة الظاهرة. هذا لا يزيل التطبيق من النظام ولا يخفيه من Launcher آخر.

يحتوي التطبيق على فحص تخزين فعلي يراجع الملفات التي يمكن الوصول إليها ويصنف الملفات الفارغة، والمؤقتة أو السجلات، والملفات الكبيرة. يعرض المسارات والأحجام فقط ولا يحذف شيئاً تلقائياً، لأن كون الملف كبيراً أو مؤقتاً لا يثبت أنه غير مطلوب. أما فحص التطبيقات فيحلل الأذونات الممنوحة ومصدر APK كإشارة إرشادية، وليس محرك كشف Malware مؤكداً.

يوجد ربط اختياري مع VirusTotal في `VirusTotalClient.kt` للاستعلام عن SHA-256. يجب توفير مفتاح API بطريقة آمنة في بيئة بناء خاصة، ويجب طلب موافقة واضحة قبل إرسال أي hash أو ملف إلى خدمة خارجية. الكود الحالي لا يرفع ملفات تلقائياً.

## البناء

افتح المجلد في Android Studio حديث مع Android SDK 35 وJDK 17، ثم نفّذ Gradle Sync وبناء `assembleDebug`. لم يُرفق APK جاهز؛ الناتج المتوقع هو ملف debug مبني من المصدر.

## قيود لا يمكن تجاوزها بصدق

لا يتيح Android SDK العام لتطبيق عادي إنشاء Virtual Space مضمون لتشغيل نسخ مستقلة من تطبيقات أخرى أو إخفاء التطبيقات المثبتة على مستوى Launcher. ذلك يحتاج صلاحيات نظام/جهاز مُدار أو إطاراً خاصاً خارج الـSDK العام، وقد يخالف سياسات التوزيع. لذلك يوفّر هذا المشروع خزنة ملفات حقيقية ولا يدّعي استنساخ التطبيقات.

`QUERY_ALL_PACKAGES` يخضع للمراجعة عند النشر على Google Play، و`MANAGE_EXTERNAL_STORAGE` صلاحية وصول خاصة لا يجوز طلبها إلا لحالة استخدام مؤهلة. حتى مع منحها لا يستطيع التطبيق قراءة مجلدات app-specific الخاصة بالتطبيقات الأخرى.
